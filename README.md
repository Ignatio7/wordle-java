# 🟩 Wordle Java

Консольная реализация популярной игры Wordle на Java с поддержкой словаря и системой подсказок.

## О проекте

Wordle Java — учебный проект, реализующий механику игры [Wordle](https://www.nytimes.com/games/wordle/index.html): игрок угадывает загаданное 5-буквенное слово за 6 попыток, получая обратную связь после каждого хода.

Проект написан в рамках курса **«Java-разработчик»** от Яндекс Практикума.

## Как играть

1. Игра загадывает случайное слово из словаря
2. Введи своё слово (ровно 5 букв)
3. После каждой попытки получаешь ответ:
   - `+` — буква есть и стоит на своём месте
   - `-` — буква есть, но стоит не там
   - `.` — такой буквы в слове нет
4. Максимум **6 попыток**
5. Застрял? Игра умеет подсказывать слово из словаря

## Технологический стек

- **Java** — основной язык
- **ООП** — наследование, инкапсуляция, полиморфизм
- **Пользовательские исключения** — обработка невалидных вводов

## Структура проекта

```
src/
├── Wordle.java                   # Точка входа, игровой цикл (main)
├── WordleGame.java               # Основная логика: попытки, проверка победы
├── WordleDictionary.java         # Словарь слов + алгоритм сравнения
├── WordleDictionaryLoader.java   # Загрузка словаря из файла/ресурсов
├── InvalidWordException.java     # Исключение: слово не 5 букв
└── WordNotFoundInDictionary.java # Исключение: слово не в словаре
```

## Архитектура

```
Wordle (main)
    └── WordleGame
            ├── WordleDictionary   ← хранит слова, сравнивает попытки
            │       └── WordleDictionaryLoader ← загружает слова
            └── Логика 6 попыток + isFinished() + suggestWord()
```

## Запуск

**Требования:** Java 11+

```bash
git clone https://github.com/Ignatio7/wordle-java.git
cd wordle-java
# Скомпилировать
javac -d out src/*.java
# Запустить
java -cp out Wordle
```

## Пример игры

```
Загадано слово из 5 букв. У вас 6 попыток.

Ваше слово: crane
Результат: + . - . +

Ваше слово: close
Результат: ++++

```
